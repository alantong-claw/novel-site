BWCamera｜更新紀錄｜截至 2026-07-04

BWCamera changelog

這頁整理 BWCamera 最近一輪從可用 debug 測試版，推進到較完整 release prep 狀態的主要修改。這裡偏產品 / 版本紀錄，和技術拆解頁分開寫。

目前版本

  • release：versionCode = 6、versionName = 0.1.5
  • release AAB：已成功重建，可供 Play Console 上傳
  • debug APK：已重建，供手機直接安裝測試

0.1.5

主題：設定面板整理、操作流收斂、上架準備、preview 問題修正

  • 設定面板整理成 拍照 / 系統 / 感謝 三個分頁。
  • 新增 感謝 頁面，列出「山大」「世豐菓園」與內測致謝文字。
  • 主選單 tab 視覺改為「選到亮、未選到暗」。
  • 補上 app 內語言切換：中文 / English。
  • 補上 狀態資訊 開關。
  • 補上 預覽品質 選項。
  • 設定頁預設展開，讓功能入口更明顯。
  • 收合設定後保留精簡控制列，包含濾鏡列與常用滑桿。
  • 加入最近照片入口與縮圖顯示。
  • 修正一個和設定頁切換有關的 preview 問題：先顯示設定頁時，第一次 hide settings 可能沒有預覽；現在已改為 app 啟動時就維持隱藏的 preview host，避免第一次切換才初始化 surface。
  • 補齊 Google Play 隱私權政策頁並已發布。

0.1.4

主題：release 版號推進與 AAB 重建

  • 將 release 版號從舊值往前推，避免 Play Console 因重複版號拒收。
  • 重新成功建出 signed AAB。

這輪持續收斂的體驗面

  • tap-to-focus 行為與狀態文案更一致。
  • 對焦模式調整為更符合實拍感受的方式，避免 UI 與底層追焦互相打架。
  • 旋轉補償可持久化，重開 app 後會沿用上次值。
  • 黑白預覽、濾鏡強度、對比、亮度、film grain 等控制已整合成較穩定的使用流程。

這輪改最多的是什麼

若從使用者直接感受到的變化來看，這輪改最多的確實是使用者 UI / 操作流。包含分頁、語言、狀態資訊、預覽品質、tab 視覺、感謝頁、收合後控制列，以及最近照片入口，都屬於這一層。
